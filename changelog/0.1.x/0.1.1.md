# 0.1.1 — 2026-10-25

## Added

- **Procedures and reference codes** — discover procedure types, filter codes and identifiers, then follow procedure stages, events, participants and document references.
- **Documents, speeches and questions** — search adopted texts and tenth-term speech activities, list committee/plenary documents and parliamentary questions, and retrieve metadata, source files and answer references; document bodies and transcripts are not extracted.
- **MEPs** — filter complete current or selected-term rosters by normalized name tokens and published codes, then read identity and membership history.
- **Plenary votes** — discover sittings, page decision summaries, retrieve rich decisions and page recorded or intended voters; optional names require an explicit parliamentary-term roster.
- **Keyless MCP access** — nine read-only tools over stdio or Streamable HTTP, with source-language provenance, snapshot continuation for local collections and matching structured/text output.
