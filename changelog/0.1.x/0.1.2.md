# 0.1.2 — 2026-10-25

## Changed

- **Speech search** accepts parliamentary terms 9 and 10, defaulting to 10; detail retrieval remains metadata and source links. ([#4](https://github.com/cyanheads/eu-parliament-mcp-server/issues/4))
- **Decision lookup** includes labels and distinct decided-on/recording document IDs in summaries, filters by document before paging, and optionally returns one MEP's separate recorded/intended positions with publication availability. ([#5](https://github.com/cyanheads/eu-parliament-mcp-server/issues/5), [#6](https://github.com/cyanheads/eu-parliament-mcp-server/issues/6))
- **Organization references** resolve membership organization IDs in ordered pages of up to 20, with per-item misses, published names and dates; historical committee/group lists retain their scope. ([#7](https://github.com/cyanheads/eu-parliament-mcp-server/issues/7))
- **Document detail** preserves adopted/based-on document relations and public-register notation without inferring procedure links or target availability. ([#8](https://github.com/cyanheads/eu-parliament-mcp-server/issues/8))
- **MEP filters** accept EPP, Greens/EFA, GUE/NGL, Patriots and GB aliases; invalid small-set filters list canonical accepted codes. ([#9](https://github.com/cyanheads/eu-parliament-mcp-server/issues/9))
- **Packaging and setup** add Agent Plugins manifests, synchronize validation and development guidance, and advertise the hosted endpoint.

## Fixed

- **Question citations** verify direct canonical candidates for every overlapping parliamentary term, preserving election-year ambiguity and operational failures without traversing the year's catalogue. ([#2](https://github.com/cyanheads/eu-parliament-mcp-server/issues/2))
- **Search paging** discloses capped totals as lower bounds, omits unreachable continuation at the 10,000-result window, and rejects window crossings before HTTP; unpublished voter arrays no longer report a false exact zero. HTTP 403 carries nonretryable rejection guidance. ([#3](https://github.com/cyanheads/eu-parliament-mcp-server/issues/3))
- **Claude Desktop bundles** preserve MCP SDK runtime modules named `skills` while removing dependency agent documentation and build-only files.
