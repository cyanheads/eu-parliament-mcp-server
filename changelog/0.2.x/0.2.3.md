# 0.2.3 — 2026-11-13

## Added

- **`euparl_get_plenary_votes` `vote_items` mode** lists a sitting's vote items in published order with `label`, `document_ids`, `procedure_ids`, `recording_document_ids` and `decision_count`; `label_contains` filters it and a row's `vote_item_id` selects its decisions. Items before the 2024-01-15 sitting omit `decision_count`, and a notice routes to decisions mode with `label_contains` (before 2019-01-14, to the minutes item). ([#43](https://github.com/cyanheads/eu-parliament-mcp-server/issues/43))
- **`euparl_search_speeches` `include_text`** (search and get) adds each speech's `text`, `speaker` and `language_tags` in the selected language only, with no fallback; search returns at most 100 rows per call with it. Every speech row gains `original_languages`. ([#42](https://github.com/cyanheads/eu-parliament-mcp-server/issues/42))
- **`euparl_search_meps` `mep_ids`** keeps the listed person IDs (any form `euparl_get_mep` accepts) from the selected roster, narrowing with every other filter; `unmatched_mep_ids` lists the IDs the roster lacks. ([#45](https://github.com/cyanheads/eu-parliament-mcp-server/issues/45))
- **`euparl_get_mep` `classification` and `active_on`** filter memberships by `membershipClassification` code and by a date inside the published interval; the overview gains `membership_classifications`, a count per code. ([#48](https://github.com/cyanheads/eu-parliament-mcp-server/issues/48))
- **`euparl_search_documents` adopted-text rows** gain `title` (requested language only), `date` and `procedure_ids`. ([#44](https://github.com/cyanheads/eu-parliament-mcp-server/issues/44))
- **`euparl_list_questions` get** returns `addressee_ids`, `alternative_title` and `original_languages`; `addressee_ids` are published verbatim and can hold an EU authority URI alone, without a Parliament code. ([#47](https://github.com/cyanheads/eu-parliament-mcp-server/issues/47))
- **Rate-limit failures** carry `retryAfter`, the wait Parliament asked for in whole seconds, beside `retry_after_ms`, which stays capped at 10 s.

## Changed

- **Adopted-text search pages** hold at most 100 rows: a larger `limit` is normalized to 100 with a notice and `next_offset`, where 0.2.2 bounded a call at 10,000 rows (1,000 for keyword searches). With `EUPARL_CLAMP_LIMITS=false`, `limit` is still accepted up to 10000. ([#44](https://github.com/cyanheads/eu-parliament-mcp-server/issues/44))
- **`euparl_get_mep` memberships** are ordered by `start_date` descending, then id, undated last; a 0.2.2 continuation snapshot fails `snapshot_changed`, so restart at offset 0. ([#48](https://github.com/cyanheads/eu-parliament-mcp-server/issues/48))
- **Unresolved voter names** notice routes to one `euparl_search_meps` call with `mep_ids` and `mandate_date` set to the sitting date. ([#45](https://github.com/cyanheads/eu-parliament-mcp-server/issues/45))
- **`eu-parliament-guide` skill** (1.3) covers vote items, speech text, historical groups, member ID lookup, membership filters and document citations.

## Fixed

- **`euparl_search_meps` `political_group`** rejected historical group codes and sent `GUE/NGL` as `THE-LEFT` on every roster. It accepts the 46 published codes and their labels; `GUE/NGL` selects `GUE-NGL` on terms 0–8 and through 2020-12-18, the last day the dated roster matches that code, and `THE-LEFT` otherwise, with a notice naming both codes. `euparl_list_reference` topic `mep_filters` lists each code with its label and version periods. ([#39](https://github.com/cyanheads/eu-parliament-mcp-server/issues/39))
- **`document_id` citations**: `euparl_search_documents` get and the `euparl_get_plenary_votes` filter rejected the citations the tools return (`A9-0188/2023`, `T9-0138/2024`, `P9_TA(2024)0138`, `RC-B9-0163/2024`) and read a lowercase identifier as unpublished or matching nothing. Both now accept citations and any letter case. ([#40](https://github.com/cyanheads/eu-parliament-mcp-server/issues/40))
- **`invalid_filter` rejections** name the parameter as written, quote the value and list the accepted codes or forms, each with its own recovery hint; reasons and error codes are unchanged. ([#41](https://github.com/cyanheads/eu-parliament-mcp-server/issues/41))
- **Decision and voter reads** failed with `invalid_filter` when a decision publishes voter entries that name no person (`person/` with no identifier, as on 2019-01-14); those entries are now left out of `voters`, `voter_counts` and `mep_position` with a notice, and the published tallies stay.
- **A malformed identifier inside a Parliament record** fails as a serialization error instead of `invalid_filter`, which blamed the caller.
