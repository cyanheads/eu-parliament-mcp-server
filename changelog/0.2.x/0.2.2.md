# 0.2.2 — 2026-11-03

## Added

- **`euparl_get_plenary_votes` `mep_id`** is accepted in decisions mode (same forms as decision mode); each decision then carries `mep_position`, from the published voter arrays with no extra upstream request. A changed normalized member invalidates the snapshot. ([#31](https://github.com/cyanheads/eu-parliament-mcp-server/issues/31))
- **`euparl_get_plenary_votes` `label_contains`** (decisions mode) selects decisions by literal label text, ignoring case, repeated whitespace and dash style; it composes with `document_id`, `vote_item_id` and `mep_id`. The no-relations notice names it. ([#32](https://github.com/cyanheads/eu-parliament-mcp-server/issues/32))

## Changed

- **`euparl_search_documents` (adopted texts) and `euparl_search_speeches`** without `text`/`title` send a stable `sort-by` and read fixed 100-row upstream pages, so walks at any `limit` return the same records without repeats; keyword searches keep relevance order and carry a notice that pages can repeat or omit records. ([#27](https://github.com/cyanheads/eu-parliament-mcp-server/issues/27))
- **Page limits** are honored independently of acquisition: locally acquired collections (`process_type` procedures, decisions, voters, MEPs, memberships, procedure sections, static reference topics) return the requested count or remaining rows with no output-size cap, and the decisions character budget is gone. Bounded upstream modes keep their acquisition bounds; `EUPARL_CLAMP_LIMITS=false` rejects a limit above a tool's largest bound only when every mode of that tool is bounded. ([#37](https://github.com/cyanheads/eu-parliament-mcp-server/issues/37))
- **Local pages past the end** return a notice with the offset and exact collection size, and say to restart at offset 0 or return to the previous page. ([#28](https://github.com/cyanheads/eu-parliament-mcp-server/issues/28))
- **Mode, snapshot and document-family rejections** carry a local recovery hint (remove or move the field, pass the previous `page.snapshot`, the six voter positions, the supported family filters). ([#36](https://github.com/cyanheads/eu-parliament-mcp-server/issues/36))
- **`euparl_list_questions` get** uppercases the `E`/`P`/`O`/`G`/`K` prefix and pads a one-to-six-digit sequence to six, so `e-000003/2025`, `E-3/2025` and `E-10-2025-3` resolve as `E-10-2025-000003`; invalid forms get question-specific guidance. ([#35](https://github.com/cyanheads/eu-parliament-mcp-server/issues/35))

## Fixed

- **Upstream reads** may spend the remaining 40 s operation deadline per attempt instead of aborting at 15 s and retrying; fast transient failures keep bounded retries. ([#30](https://github.com/cyanheads/eu-parliament-mcp-server/issues/30))

## Dependencies

- **vitest** ^5.0.5 → ^5.1.0, **@vitest/coverage-istanbul** 5.0.5 → 5.1.0.
