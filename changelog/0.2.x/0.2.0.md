# 0.2.0 — 2026-11-01

## Added

- **`skill://eu-parliament-guide/SKILL.md`** is served as a resource and listed in `resources/list`; the server instructions point to it. It covers identifier chains, the term calendar, final-vote selection, and a voter's country on the vote date.
- **`euparl_search_meps` `mandate_date`** (`YYYY-MM-DD`, not after today UTC, exclusive with `term`) returns the members seated on that date. ([#16](https://github.com/cyanheads/eu-parliament-mcp-server/issues/16))
- **`EUPARL_CLAMP_LIMITS`** (default `true`) clamps an oversized `limit` to the collection's cap with a notice; `false` rejects a `limit` above the tool's largest cap. Mirrored in `.env.example`, `server.json`, `manifest.json` and the plugin manifests. ([#14](https://github.com/cyanheads/eu-parliament-mcp-server/issues/14))

## Changed

- **Page caps** are per collection, sized so a full page stays under the 100,000-character client output cut. ([#14](https://github.com/cyanheads/eu-parliament-mcp-server/issues/14))
  - 300: procedures, questions, MEP roster
  - 225: documents, memberships
  - 125: procedure sections
  - 100: sittings, decisions
  - 80: speeches (was 100)
  - 1,000: voters
  - 350: reference lists
  - 20: organization lookups
- **`tools/list`** advertises no `maximum` on `limit` by default. Clamps log once per collection and count in `euparl.limit.clamps`. ([#14](https://github.com/cyanheads/eu-parliament-mcp-server/issues/14))
- **Search window**: a page crossing the 10,000-result window narrows to the results left instead of being rejected; an offset of 10,000 or more fails `invalid_filter` with a hint (no narrower filter exists once `process_type` is set). ([#14](https://github.com/cyanheads/eu-parliament-mcp-server/issues/14))
- **`euparl_get_procedure`** sorts events and participants (date, undated last, then id), documents by `document_id`, and nested ID arrays before hashing and slicing, so continuation snapshots hold across upstream reordering. Output order changes; a procedure snapshot minted by 0.1.2 fails `snapshot_changed` once. ([#13](https://github.com/cyanheads/eu-parliament-mcp-server/issues/13))
- **Country filter**: United Kingdom is sent and echoed as `GB` (`UK` stays an alias), so `appliedFilters.country` reads `"GB"` where it read `"UK"`. ([#17](https://github.com/cyanheads/eu-parliament-mcp-server/issues/17))

## Fixed

- **`euparl_list_questions`** accepts `G-` and `K-` interpellation IDs and their `X-NNNNNN/YYYY` citations; other letter prefixes fail `invalid_filter` naming the accepted E/P/O/G/K forms. ([#11](https://github.com/cyanheads/eu-parliament-mcp-server/issues/11))
- **`euparl_search_meps` `name_contains`** with no letter or digit is rejected before any upstream request; it returned the whole roster. ([#12](https://github.com/cyanheads/eu-parliament-mcp-server/issues/12))
- **Date validation** (`sitting_date`, `sitting_date_end`, a vote `sitting_id` date, `mandate_date`) carries its own recovery hint, including for a reversed range, in place of a reference-topic hint. ([#24](https://github.com/cyanheads/eu-parliament-mcp-server/issues/24))
