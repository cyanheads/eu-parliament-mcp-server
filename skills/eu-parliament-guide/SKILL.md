## Scope

Use this guide when an answer needs more than one Parliament record: a file's path from report to vote, a member's or delegation's recorded position, the debate on a file, or membership at a past date. The server reads European Parliament Open Data without a key: procedures, Parliament documents (metadata and file links) including MEP conflict-of-interest declarations, plenary sittings (from 2014; earlier years return none) with their published agenda items (from the 2024-12-16 sitting, plus the weeks of 2023-07-10 and 2024-04-22), vote items, decisions and roll-call voters (decision records start with the 2019-01-14 sitting; earlier sittings list but return no decisions, and not every later sitting has them), speech metadata and, on request, speech text for terms 9 (from July 2021) and 10, members and their membership history, and parliamentary questions.

It does not read the text of any document or answer; files are linked, not opened. Speech text comes only from euparl_search_speeches with include_text, in one language. Commission and Council records are outside it, and so is the enacted act: a procedure records its Official Journal publication date but links no published act.

## Identifiers

| Identifier | Form | Comes from | Goes to |
|:--|:--|:--|:--|
| Procedure | reference `2021/0106(COD)`, canonical `2021-0106` | euparl_list_procedures, an agenda item's `procedure_ids`, or the user | euparl_get_procedure; the adopted-text procedure filter of euparl_search_documents |
| Document | `TA-9-2024-0138`, in any letter case; its `label` is the citation `T9-0138/2024`, also accepted as `P9_TA(2024)0138`; reports `A9-0188/2023` or `P9_A(2023)0188`, motions `B9-0163/2024` and `RC-B9-0163/2024`, agendas `P9_OJQ(2024)03-13` | document search (declarations: source `mep_declarations`), procedure events and documents, agenda items, decisions, speeches, question answers | euparl_search_documents get; the decisions document filter |
| Person | decimal `197394`; `person/197394` in creator lists | euparl_search_meps, voters, speech and procedure participants, creator lists | euparl_get_mep, speech search, decision member lookup, euparl_search_meps `mep_ids` |
| Sitting | a date `2024-03-13` or `MTG-PL-2024-03-13` | procedure event dates, sittings mode | euparl_get_plenary_votes |
| Decision | `MTG-PL-2024-03-13-DEC-166051` | decisions mode only | decision and voters modes, with its sitting |
| Vote item | `MTG-PL-2025-12-17-VOT-ITM-978508` | vote_items mode; a procedure's `PLENARY_VOTE_RESULTS` event; a decision's `vote_item_ids` | decisions mode `vote_item_id`, with the sitting on its date |
| Agenda item | `MTG-PL-2026-11-24-OJ-ITM-V-69` (`-D-` debate, `-V-` vote) | agenda_items mode | nowhere: not a `vote_item_id`; its `procedure_ids` go to euparl_get_procedure and its `document_ids` to euparl_search_documents get |
| Organization | decimal `org/5154`; case-sensitive code `org/IMCO`, `org/S-D`, `org/ep-9`, `org/EU_PARLIAMENT` | membership history; procedure participants, document creators, term fields | euparl_list_reference organizations |
| Addressee | `org/COM`, `org/EU_COMMISSION`, `org/EU_COUNCIL`, `org/HRVP`; some records publish an EU authority URI beside such a code or in its place | a question's `addressee_ids` | nowhere: not organizations lookups (below); the question's `alternative_title` names the addressee |
| Question | `E-9-2023-000003`, citation `E-000003/2023`; answer `E-9-2023-000003-ASW` | euparl_list_questions | question get; answers go to document get |

Document identifiers name their family:

| Prefix | Record |
|:--|:--|
| `TA-` | text adopted in plenary |
| `A-` | committee report tabled for plenary; `A-…-AM-808` is its amendment 808 |
| `B-` | motion for a resolution |
| `RC-` | joint motion for a resolution |
| `QOB-` | motion for a resolution tabled on a question |
| `C-` | proposal as referred to Parliament; detail is usually unpublished (found false) |
| `DCI-` | MEP conflict-of-interest declaration (`DCI-124867-2026-03-12-540997`), found by search source `mep_declarations` and read with document get; `previous_version_ids` and `superseded_by_ids` name the declarations it replaces and is replaced by |
| `ENVI-PA-`, `ENVI-AD-` | a committee's draft opinion, adopted opinion (the prefix is the committee code) |
| `CJ40-PR-`, `CJ40-AG-` | draft report, provisional agreement (`CJnn` is a joint committee) |
| `CRE-9-2024-03-12` | verbatim report of a sitting day; `-ITM-012` one agenda item, `-OTH-…` one speech |
| `OJQ-9-2024-03-13` | agenda (citation `P9_OJQ(2024)03-13`) |
| `PV-9-2024-03-13` | minutes; `-VOT-ITM-` vote results, `-RCV-ITM-` one roll-call record |
| `E-` `P-` `O-` `G-` `K-` | written, priority written, oral question; major, minor interpellation |

Procedure participants name committees and political groups by code (`org/IMCO`, `org/S-D`), and document creator lists name committees the same way. The organizations topic resolves a code to the body's name and classification; codes are case-sensitive, so `imco` comes back found false. It does not resolve a question's `addressee_ids` (there `COM` is the Communist and Allies Group, and `EU_COMMISSION`, `EU_COUNCIL` and `HRVP` return no name), and it rejects an EU authority URI (`http://publications.europa.eu/resource/authority/corporate-body/…`) in `creator_ids`; read the addressee from the question's `alternative_title`. Membership history carries decimal IDs for committees and groups, one per period (the committees topic lists them, labelled by code), and the organizations topic dates each; term memberships use the code `org/ep-N`. A term field of `org/ep-9` means term 9. Memberships come latest start first; the euparl_get_mep overview lists the classification codes a history carries in `membership_classifications`, and the memberships section takes `classification` and `active_on` (a date) to select rows before paging. Member records publish the term membership twice, once with classification `EU_INSTITUTION` and once unclassified with role `MEMBER_PARLIAMENT`, so `classification` `EU_INSTITUTION` finds the term periods but not the `MEMBER_PARLIAMENT` rows.

Terms are five-year mandates numbered from the first direct election: term 1 began 1979-07-17. Term 8 ran 2014-07-01 to 2019-07-01, term 9 2019-07-02 to 2024-07-15, and term 10 began 2024-07-16.

Question get accepts E/P/O/G/K prefixes in either case and pads one-to-six-digit sequences: `e-3/2025` and `E-10-2025-3` resolve as `E-10-2025-000003`. Human citations without a term still require a unique verified match across overlapping terms; answers use document get.

## Gates

- **Set the term from the date before** naming voters, searching speeches, or reading a past roster. A wrong roster term is not rejected: it leaves voters unresolved, as when a March 2024 vote is looked up against term 10. Speech search defaults to term 10, so a term-9 date returns nothing; the empty-result notice names the term searched. Term-9 speech records start in July 2021, so an earlier date returns nothing in either term.
- **Get the procedure reference before procedure work.** No tool maps a topic to its procedure: the procedure list has no keyword filter. A document leads there: document get lists the procedure of an adopted text, report, motion or committee document in `procedure_ids`, and adopted-text search rows carry `procedure_ids` as well. A notice that `procedure_ids` may be incomplete means that relation was not read; repeat the get before treating the list as complete. Without a document, ask the user or another source for the `YYYY/NNNN(TYPE)` reference.
- **Find a final vote through its vote item, not the document filter.** A final vote often decides on no document, so `document_id` misses it. The procedure's `PLENARY_VOTE_RESULTS` event id is the vote item: `vote_item_id` with that event's date as the sitting returns every decision of the vote. When `document_id` leaves out decisions of a vote item it matched, its notice names that vote item. Without the event id, vote_items mode lists what a sitting voted on, each item with its title, report documents, procedures and `decision_count`; `label_contains` selects by title. Vote items before 2024-01-15, the first sitting of 2024, publish no decision links (`decision_count` is absent), so `vote_item_id` selects none of their decisions, and their decisions carry no report relations. From the 2019-01-14 sitting, the first with decision records, use decisions mode with label_contains set to the report citation to select decision labels (a `document_ids` entry is cited with its prefix and term joined and the year after the number: `A-9-2022-0116` is `A9-0116/2022`, the joint motion `RC-9-2022-0257` is `RC-B9-0257/2022`); some labels carry no citation, so try words of the vote item's title with `language` set to the title's language (vote item titles are French through 2023, and French words match nothing under the default `en`). Before it no decisions exist; a vote item's `recording_document_ids` names the minutes item that records it, readable with document get. The literal filter ignores case, whitespace and dash style; inspect the selected items before naming a final vote.
- **Name what was voted.** A label runs from the report citation and rapporteur (sometimes after a title) to the item voted, and some hand-vote labels carry the item alone. The item is an amendment (`Am 220-223`, `§ 25/2`, `Recital I`), `Provisional agreement – Am 808`, `Commission proposal`, `Motion for a resolution (as a whole)`, `Decision to enter into interinstitutional negotiations`. Report that item. One file can be voted at several sittings (amendments and a referral back for negotiations, then the provisional agreement months later), so match the sitting to the stage asked about.
- **Check voter_counts before a member-level answer.** Only a decision whose voter_counts lists a position with a count above zero has voters to page. Hand votes typically carry an outcome only, and electronic or secret votes tallies only. Some decisions (2019-01-14, 2019-03-27, 2019-04-04) publish voter entries that name no person: they are left out, voter_counts reads 0 beside tallies that stay as published, and a notice says so, so the tally is the answer there. Without arrays, report the outcome or tally and say member positions were not published.
- **Take a voter's country from a roster of the vote's date, never from today's.** For how each political group or country voted, one decision-mode call with `breakdown` true tallies the recorded voters by the group and country the roster for the sitting date publishes, instead of paging voters and joining a roster by hand. Its rows use the published labels (`S&D`, `The Left`) and alpha-2 codes, which go back into euparl_search_meps with the same `mandate_date`; `unmatched_mep_ids` lists recorded voters the roster lacks, counted in no row, and a decision that does not publish all three recorded voter arrays (hand votes) or whose arrays name no person (some 2019 roll calls) returns no `breakdown` and a notice. Voter rows carry IDs and optional names only. For "who was this voter on the day", make one euparl_search_meps call with `mep_ids` set to the voter IDs and `mandate_date` set to the sitting date and `limit` at least the voter count: it returns each member's name, country and group as published that day, and `unmatched_mep_ids` names IDs that held no seat then, which euparl_get_mep reads by ID. The dated roster (euparl_search_meps with a mandate date) lists who held a seat that day. A term roster filtered by country lists everyone who sat for it during the term (seven for Malta in term 9, one of whom left in 2020); confirm a candidate's seat on the vote date from their `org/ep-N` membership with role `MEMBER_PARLIAMENT`. Today's roster (omitted term) fits only votes held now.
- **Read affiliation at a date from the dated roster or membership history.** A roster with `mandate_date` publishes each member's group on that date; `political_group` there takes historical codes (`PPE-DE`, `ALDE`, `GUE-NGL`; the `mep_filters` reference lists them with periods) and matches only the code in force that day. `GUE/NGL` names two codes and is sent as `GUE-NGL` on terms 0–8 and dates through 2020-12-18, `THE-LEFT` otherwise (term 9 included); the notice names the other and the date or term that reaches it. On a term roster a group code matches members holding a membership in it not ended when the term began, not who sat in the group during the term. For a membership history, the `EU_POLITICAL_GROUP` membership interval gives the group on a date; resolve its decimal ID with the organizations topic. Group organization IDs change each term (S&D is `org/4284` in term 8, `org/5154` in term 9).
- **Do not enumerate a member's questions.** Questions have no author, addressee or keyword filter, list rows carry no author, and the list reports no total. Ask for the citation; a question's `person/` creators open with euparl_get_mep (it rejects committee and group creators). Committee `org/` creators resolve with the organizations topic, but an EU authority URI in `creator_ids` (`http://publications.europa.eu/resource/authority/corporate-body/…`) does not. Question detail also lists `addressee_ids` and `original_languages`; the addressee is named in words by `alternative_title`, and `addressee_ids` do not resolve through the organizations topic.
- **Missing is not negative.** A `C-` proposal returning found false, an empty answers list, an empty member position, an event without documents, or a declaration search with no rows describes what was published, not what happened.

## Paging

Whole-acquired rosters, memberships, procedure sections, agenda items, vote items, decisions, voters, process_type procedures and static reference tables honor the requested limit or remaining rows, without a character budget. Local continuation needs the returned snapshot except process_type procedures, where it is optional. A past-end page of a nonempty local collection gives its exact total and restart guidance; snapshot drift fails before slicing.

Non-keyword adopted-text, speech and MEP declaration listings use fixed aligned 100-row upstream pages, independently of the requested limit; a caller page may span several requests within the shared deadline. Adopted texts sort by document ID; speeches by sitting date and numbering. Parliament orders a set of more than 100 declarations differently with each request geometry, so each declaration call sorts its aligned pages by document ID, and when more than 100 match, pages can repeat and omit declarations: narrow by `person_id`, `related_process_id`, `title`, `year`, `term` or `awareness_of_conflict` until 100 or fewer match, which arrive whole. Text or title keywords retain relevance order and can repeat or omit records across pages. Follow next_offset within the 10000-result window and narrow supported filters when continuation ends. Unfiltered procedures retain their ordering caveat. An adopted-text page, keyword or not, a declaration page, and a speech page with include_text hold at most 100 rows; a non-keyword speech page holds at most 400 and a keyword speech page at most 1000; adopted-text rows carry title, date and procedure_ids. Upstream-paged procedures, questions, committee/plenary documents, keyword speech searches, live reference bodies and sittings have verified acquisition bounds of 1000 rows per request; organization lookups remain at 20 paced requests. Larger bounded-mode limits narrow with a notice; EUPARL_CLAMP_LIMITS=false rejects limits above an entirely bounded tool's largest bound, with adopted texts, speeches and MEP declarations counting their 10000-result search window. Very large finite limits normalize to the safe-integer range.

## Core chain

1. euparl_get_procedure overview gives section counts; read the events section next.
2. Events seldom carry sitting relations, so their dates route onward. The `PLENARY_VOTE_RESULTS` event names the procedure's own report (`A-…`) and the vote date, and its id is the vote item. `PLENARY_VOTE` events can list every report voted under one agenda item, so do not take the report from them. `PLENARY_DEBATE` gives the debate date and its `CRE-…-ITM-…` item. Committee events carry the opinions and draft reports.
3. Pass the vote date as the sitting and the `PLENARY_VOTE_RESULTS` event id as `vote_item_id` to euparl_get_plenary_votes, then pick the decision (gates above). Without the event id, list the sitting's vote items with mode vote_items and take the one titled for the file. On sittings whose vote items carry no decision links, use decisions mode with `label_contains` set to the report citation (written as in the gate above), or to words of the vote item's title, with `language` set to the title's language, where the label carries none; this literal substring ignores case, repeated whitespace and dash style, and does not establish a final vote. Add `mep_id` in decisions mode for one member's positions across the selected decisions, or in decision mode for rich detail. Recorded and intended positions stay separate; empty matches never prove absence. For a delegation or the whole chamber, page voters by position.
4. The adopted-text filter on the procedure reference returns the file's adopted texts; an adopted text's adopted documents name the report it adopts. Going the other way, an adopted text's or report's `procedure_ids` name its procedure.
5. For the debate, search speeches with the debate date, the term for that date, and title words from the debate's `CRE` item; results also carry written statements and procedural records, so count speeches by `activity_type`. Set include_text to read the published text of each speech with its speaker line, in one language and without fallback; `original_languages` says which language a speech was given in, and chair rows publish no title. A speech belongs to the procedure's debate when its recording document's parent is that event's `CRE-…-ITM-…` item. One debate item can cover several files (a joint debate lists each file's report on its event).
6. For files, read the document; when it has no links, follow parent documents. A speech's recording document reaches files in two parent hops, the agenda item and then the sitting day, whose files are multilingual (`mul`). Roll-call records reach the day's `PV-…-RCV` document the same way.

## Workflows

### Committee and rapporteurs on a file

The participants section of euparl_get_procedure carries roles such as `COMMITTEE_LEAD`, `COMMITTEE_OPINION`, `COMMITTEE_OPINION_ASSOCIATED`, `RAPPORTEUR_CO`, `RAPPORTEUR_OPINION` and `RAPPORTEUR_SHADOW`. A rapporteur's represented organization is the committee they act for, and the political group is the one recorded with that participation. Open people with euparl_get_mep.

### Did anyone working on a file declare a conflict?

1. Run euparl_search_documents with source `mep_declarations` and `related_process_id` set to the file's procedure, or with `person_id` for each participant that euparl_get_procedure lists. `awareness_of_conflict` true or false selects declarations of an awareness of a conflict or those declaring none; `title` matches the member, capacity, committee and procedure a declaration title names. Keyword `text` and sitting dates are not accepted.
2. Read `awareness_of_conflict`, `conflict_description` (verbatim, when published) and `capacities` on each row: one entry per participation, with the role, committee, political group and procedure the member declared in. Declarations are versioned; `superseded_by_ids` names a later declaration that replaces the row. Some declarations publish a procedure reference that is no procedure identifier (`eli/dl/proc/2023-02735`): the notice names it, and `procedure_ids` and `procedure_id` leave it out. Do not repair it into an identifier: `2023-2735` is a different procedure.
3. An empty result means Parliament publishes no declaration under that filter, not that no one involved had a conflict. `term` and `person_id` cannot be combined; narrow a member's declarations by `year` instead.

### What a sitting will debate and vote on

Vote items and decisions appear only after the vote, so for a coming or current sitting use euparl_get_plenary_votes mode agenda_items with the sitting date: its debate, vote and urgency-vote items in agenda order, each with its time-slot start, `procedure_ids` and `document_ids`. Take the file from `procedure_ids` (euparl_get_procedure) and the proposal or report from `document_ids` (euparl_search_documents get). An empty page does not say whether the agenda is unpublished or the date has no sitting: check the date with mode sittings, its year and limit 100, which lists the whole year in one call. Agendas change until the sitting and a moved item changes ID, so re-read it rather than keeping an `agenda_item_id`.

### Who sat for a country on a date

For today, filter the current roster by country. For a past date, pass it as the mandate date with the country filter. A term's first sitting day is unreliable upstream (an error, or a partial roster), so use the following day when the term boundary is not the question. To cross-check, filter the term roster and read each candidate's `MEMBER_PARLIAMENT` interval in their membership history; the term roster alone overcounts members who left or arrived mid-term.
